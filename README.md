# Thesis\_BXM





\# DJI 30 掩護性買權量化回測引擎 (Covered Call Backtesting Engine)



本專案為一套基於 R 語言開發的量化回測系統，專為道瓊工業平均指數 (DJI 30) 成分股的掩護性買權 (Covered Call) 策略所建構。系統設計重點在於解決龐大歷史期權數據的運算瓶頸，並確保財務現金流還原的精確度。



\## 核心開發方法與工程架構



本專案從底層資料管理到最終報表產出，實作了以下技術與處理邏輯：



\### 1. 資料庫整合與底層效能優化



\* \*\*SQL 動態查詢與整合:\*\* 面對長達十餘年的海量歷史數據，捨棄將全數資料載入記憶體的低效作法，改採 RSQLite 建立輕量化資料庫連線，依需求動態查詢股價、配息與無風險利率。

\* \*\*Rcpp 底層加速:\*\* 針對量化回測中高密度的運算瓶頸與複雜的資料處理迴圈，系統架構整合了 Rcpp，透過 C++ 處理底層運算以大幅提升 R 語言的執行效率，確保大規模回測的效能。

\* \*\*記憶體快取 (Cache) 機制:\*\* 針對極度消耗 I/O 資源的期權合約檔案，於運算迴圈中實作 rds\_cache 記憶體快取。避免重複讀取相同月份的檔案，縮短量產回測的執行時間。



\### 2. 核心回測引擎與財務校正



\* \*\*企業行為精準還原:\*\* 回測引擎內建嚴格的財務校正邏輯。在計算每期損益時，同步處理了現金股利的收益疊加，以及股票分割 (cfadj) 的比例調整，確保投資組合的成本與報酬不因除權息而失真。

\* \*\*動態交易日曆:\*\* 整合 timeDate 套件中的 holidayNYSE，動態生成並對齊結算日，精確處理遇到國定假日需提前結算的特殊市場規則。

\* \*\*邊界查找優化:\*\* 開發 get\_stock\_row\_fast 等輔助函數，利用 dplyr 進行時間窗格的邊界查找，有效處理歷史資料偶發的缺漏值問題，提升系統穩定度。



\### 3. 自動化報表交付



\* \*\*量化指標運算:\*\* 運用 xts 處理財務時間序列，並整合 PerformanceAnalytics 模組，自動化計算年化報酬、最大回撤 (MDD)、夏普值、Beta 等專業風險調整指標。

\* \*\*端到端 Excel 輸出:\*\* 結合 openxlsx 套件，在迴圈終點自動將交易明細、績效矩陣以及視覺化資金曲線圖打包輸出為多頁籤的 xlsx 商業報表，達到無須人工二次加工即可交付的標準。



> 註：為遵守資料供應商授權規範，本專案僅展示核心演算法邏輯與資料處理流程，不包含歷史期權與股價之原始資料庫。
